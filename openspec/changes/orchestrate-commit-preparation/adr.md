# ADR Review Manifest

- Status: completed

## Review Summary

До этого change ADR и их индекс отсутствовали. Повторно проверены долговременные решения [design](design.md) после завершения задачи 2.8 и выбора single-version миграции Paseo; выделены источники восстановления, технологическая граница адаптеров и идентификация собственной сессии после прямой отправки. Подтверждённая интеграционная граница использует только штатные JSON-команды Paseo CLI. ADR 0002 уточнён стабильным доменным интерфейсом и заменяемым внутренним адаптером единственного активного контракта; точный текущий выпуск, схемы команд и процедура его квалификации остаются локальными решениями design.

Design согласован с тремя предложенными ADR и [терминами контекста](../../../CONTEXT.md). Активный workspace находится по служебному имени и cwd, а видимая активная собственная сессия — по серверным фильтрам меток с полным ID workspace и последующему `inspect`. Завершение подготовки коммитов определяется свежей чистотой Git после прекращения работы или закрытия сессии. Предварительное резервирование и структурированный результат агента не используются. Узкое окно потерянного ответа на создание принято для ручного режима и явно ограничено условиями пересмотра. Координация параллельных поручений разных change остаётся ответственностью пользователя. Подтверждённая граница поставки ограничена Linux, локальным daemon того же пользователя и локальными рабочими каталогами. Одновременно поддерживается ровно один точный выпуск Paseo; миграция заменяет активный CLI-контракт без ветвей обратной совместимости и заново подтверждает стабильный доменный интерфейс.

Проверка и согласование ADR завершены. Все ADR этого change остаются `proposed` и редактируемыми до архивирования; этот манифест не означает одобрение человеком или успешную проверку реализации.
